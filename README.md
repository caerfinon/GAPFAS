# GAPFAS - A GAP For All Systems
Provides flight contracts to Kerbal Konstructs bases on any Home World planet 

Requires
 - Contract Configurator
 - Waypoint Manager
 - Ketbal Konstructs

Suggests
  - NavUtilities continued
  - Kramax Autopilot Continued
  - MechJeb2
  
Manual Instalation

Move the folders within the GameData folder in the ZIP archive into your game's GameData folder
