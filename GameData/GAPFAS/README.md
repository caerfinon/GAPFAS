# GAPFAS - A GAP For All Systems
Provides flight contracts to Kerbal Konstructs bases on any Home World planet

## Requires

- Contract Configurator
- Waypoint Manager
- Module Manager
- Ketbal Konstructs

## Suggests

- NavUtilities continued
- Kramax Autopilot Continued
- MechJeb2

## Installation Requirements
Place the GAPFAS folder in your GameData folder

- In the folder GameData\GAPFAS\Patches there is a file called GAPFASContractGroupPatch.cfg.StockTemplate
- Copy this file to a directory in your GameData where you normally keep your Module Manager patch files
- Rename the file to GAPFASContractGroupPatch.cfg
- This is the file you will edit to define your world's bases
